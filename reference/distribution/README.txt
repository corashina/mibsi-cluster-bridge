MIBSI - QUICK GUIDE
Package firmware: MHI2Q_ER_AUG22_P5092_MU1329

Extract the downloaded package to get install.zip and uninstall.zip.

INSTALLATION
1. Extract install.zip to the root of an empty FAT32 SD card.
2. Insert the card into the MMI. Open the red update menu and select
   Update > your SD card > Standard, then start the update.
3. Wait for completion, remove the SD card and restart the MMI.

UNINSTALLATION
1. Extract uninstall.zip to the root of an empty FAT32 SD card.
2. Insert the card into the MMI. Open the red update menu and select
   Update > your SD card > Standard, then start the update.
3. Wait for completion, remove the SD card and restart the MMI.
This restores the files backed up before installation.

UPDATING
Follow the installation steps with the new install.zip.
No uninstall is needed; the original backup is kept.

metainfo2.txt and Bootstrap must be directly at the SD card root.
Keep the MMI powered and the SD card inserted until completion.
If an error occurs, send support the message and, if available,
MIBSI-Logs/install.log from the SD card.
